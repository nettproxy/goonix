# Goonix

Goonix is a UNIX-like Operating System/Kernel developed entirely from scratch from only one developer. It currently only supports the i386 Processor (32-bit), but 64-bit support is planned.
Goonix is focused on on performance and stability.

---

## 🤝 Contributing

Are you interested in contributing to Goonix? Beautiful!
When making a PR; please be sure to: 
- **Test the changes** and show a demo/screenshot of the implemented code working.
- **Please** explain what your changes do and what they are useful for.

## 🛠️ Building Goonix

Following dependencies are required to run Goonix: 
1. `qemu-system nasm mtools gcc-multilib xorriso`
2. Build: `cd /build; chmod +x build.sh; ./build.sh`
